# 動画を加工する契約

最終更新: 2026-10-12-1740

- 元動画は読み取りだけ。解析前後・書き出し前後の SHA-256 を比較する。元動画と既存の出力は上書きしない。
- 出力は入力動画と同じフォルダに `{入力の stem}_mosaic.{選択した形式の拡張子}` で自動保存する。保存先ダイアログは出さない。同名の出力がある場合は `_mosaic_1`、`_mosaic_2`…と、空いている最初の番号を拡張子の前に付ける。同名のディレクトリやリンクも使用済みとして扱う。書き出し中に候補名が使われた場合も、完成済み動画を再エンコードせず次の番号で公開する。
- 顔候補のチェックはすべて初期状態 OFF。検出した全顔は原則隠す。
- 人物候補は複数列の顔カードで表示し、拡大一覧を開ける。並べ替え・選択済みの絞り込みにかかわらず、元の人物 ID に表示許可を保持する。通常一覧と拡大一覧は同じ選択モデルを使用する。顔写真のクリックは登場位置への移動だけで、雲を外す許可を与えない。チェック、スペースキー、またはプレビューの雲のクリックで明示的に選択する。拡大一覧を閉じても選択は保持し、次の動画を解析すると全選択を初期化する。
- プレビューの雲の左クリックは、確実に識別された人物候補なら同じ候補の全フレームを表示許可にし、一覧のチェックも同期する。人物不明・曖昧な識別の場合も、その連続した検出の追跡 ID を明示的に除外できる。除外 ID は人物 ID と別で、カット・欠落・長い間隔・人物判定の変化・近くの対象との曖昧な対応で更新し、除外許可を他の対象へ移さない。雲の配置・クリッピング後の透過を使って判定し、重なる場合は描画順の最前面だけを対象にする。手動追加範囲では解除せず、背後の人物にも適用しない。クリック時は再生と未反映のスクラブを停止して表示フレームを保持する。処理中、範囲追加モード、ドラッグ、右クリック、映像外の余白、PNG の完全透明部分では解除しない。クリックは人物・追跡 ID とも履歴に残し「外した雲を1つ戻す」で取り消せる。一覧のチェック解除でも人物を隠せる。通常画面と拡大一覧の「すべての顔を隠す」は人物選択・追跡除外・履歴・検出閾値を標準へ戻す。
- 候補のまとまりと、顔を表示する許可は別判定。表示には明示選択、十分高い識別スコア、他候補とのスコア差が必要。同一フレーム内の複数顔を同一候補に割り当てた場合は隠す。
- 未分類、小さい顔、曖昧な分類、追跡だけで補った顔は人物候補の選択では表示許可にしない。利用者がその追跡 ID をクリックで除外した場合と、検出閾値未満の場合は加工対象から外す。手動追加範囲はこれらの除外と閾値の影響を受けない。
- 顔検出を最低スコア 0.30 で解析し、実スコアを保持する。「顔を見つける細かさ」は 0.30〜0.99、標準 0.80。変更は再解析・再デコードせず、プレビューと書き出しで同じフィルターを使う。検出の保持期間 0.5 秒は、実スコアの履歴も保持する。低スコアの再検出で過去の高スコアを早く消さず、低スコアだけで高い値を延長しない。カットで履歴を破棄する。閾値を高くすると人間の顔も加工対象外になり得ることを設定内に明示する。
- 解析は全フレームで実行。標準の高速モードは顔検出画像だけ長辺 1920px 以下に縮小し、顔矩形と全ランドマークを元座標に戻して、元画像で人物識別する。「小さい顔重視」は元解像度で検出する。解析方法を変更すると再解析し、人物選択・追加範囲・確認を初期化する。
- 顔検出と識別はモデルを共有しない 4 本の並列処理（OpenCV 各 2 スレッド）で実行。最大 8 枚のフレームを待機させ、完了順にかかわらず入力時刻順に集約する。解析デコードは VideoToolbox を優先し、最初のフレームまでの初期化に失敗した場合は AUTO / 2 スレッドのソフトウェア処理に切り替える。途中から失敗した場合は中断し、部分結果の再集約はしない。書き出しのデコードは従来のネイティブ形式を維持。キャンセル・例外時は未着手処理を破棄し実行中の処理の終了を待つ。
- 一時的な検出漏れを、長辺 960px 以下の追跡画像で全顔の optical flow を一括計算し、元座標に戻して最大 0.5 秒の保持で補う。検出を一度も受けていない顔は、この補完では隠せない。追跡画像の縮小や高速モードは小さい顔・急な動きの検出精度に影響する。
- 解析後の顔矩形を時間に基づいて安定化し、プレビューと書き出しで同じ矩形を使う。位置の許容幅は顔サイズの 15%（6〜24px）、位置の平滑化は時定数 0.25 秒。大きな移動ほど連続的に追従を速め、中心の遅れは直近 0.6 秒の各辺の最大寸法の 25% 以下に抑える。安定化した矩形は常に元の顔矩形全体を含む。寸法には 15% の余裕を持たせ、縮小を控える幅は 12%（最低 5px）。十分小さい状態が 0.6 秒続いてから時定数 0.45 秒で縮める。上限は直近 0.6 秒の顔寸法の最大値の 1.5 倍とし、瞬間的な寸法の揺れで上限を下げない。人物 ID・表示許可に関わる判定は元フレームの値を保持し、追従から引き継がない。カット、欠落、長い時間間隔、対応しない位置やサイズでは新しい追従状態を開始する。追加した固定範囲は安定化しない。
- 追加範囲は動画全体の固定位置。追加範囲には人物を表示する選択を適用しない。
- 利用者が選ぶ PNG の中央の縦横 50% は読み込み後に不透明にする。元 PNG の中央に alpha 128 未満の点がある場合は拒否し、それ以外は中央だけ alpha 255 にする。元ファイル・RGB・中央以外の alpha は変更しない。合成時は約 2.2 倍以上の大きさで配置。縁の透過は保持する。
- 同梱の既定画像は利用者指定の PNG をファイル内容そのままで収録し、元の RGBA と寸法を読み込む。縮小、白色化、中央の不透明化、輪郭の再生成を行わない。動画への追従合成で必要な配置と拡大縮小は適用する。
- 画面の出力形式は MP4 と MOV の2種類。MKV は選択肢に含めない。MOV は編集用 ProRes 422 HQ / 10bit / 4:2:2 を使用し、完全な可逆圧縮や元画素の完全一致を保証しない。ネイティブ YUV の各平面に直接合成し、合成時に alpha が 0 のサンプルは書き換えない。色差平面には alpha と色の積を縮小して合成する。その後、出力のピクセル形式への変換と圧縮を行う。元の 8bit や 4:2:0 の映像に存在しない情報を復元するものではない。
- 書き出しの合成は 4 本の独立した処理で実行し、映像と音声を入力順に戻す。待機は最大 8 イベント。合成前にデコード済みフレームを writable にし、デコーダーが参照する共有画像への変更を防ぐ。PNG の前処理と合成係数は処理ごとに再利用し、係数キャッシュは各 64 MB 以下に制限する。補間・丸め・色変換・顔の重なり順は維持する。
- HLG 入力には sRGB PNG を BT.2020 / HLG に変換して合成する。MP4 と編集用 MOV は PNG の `#fff` を HLG 信号の最大白 1.0（10bit limited の Y=940）へ対応させ、基準白 0.75 への減光を行わない。色の変換と白の明るさの指定は動画への合成時だけ適用し、PNG の元ファイル・RGBA・透過境界を変更しない。プレビューのみ SDR にトーンマップする。元動画全体の SDR 変換は行わない。MP4 / MOV の非可逆圧縮、RGB/YUV の丸め、プレイヤーの HDR 表示による各画素の完全な `#fff` 一致は保証しない。
- MP4 は非可逆。対応音声は再圧縮しない。HLG MP4 は VideoToolbox の Main10 HEVC、SDR MP4 は利用可能なら VideoToolbox の H.264 を使用する。H.264 の初期化失敗時はソフトウェア圧縮に切り替える（同梱版は OpenH264 の高ビットレート、clone 版は libx264 があれば CRF 16）。非対応音声は AAC に変換し、映像は一度だけエンコードする。変換後の結合は PyAV でパケットをコピーし、映像の PTS / DTS / duration と圧縮済みデータを保持する。
- MOV は VideoToolbox の ProRes 422 HQ を優先し、初期化できなければ同梱の prores_ks / HQ に切り替える。対応 AAC / ALAC / MP3 / PCM は再圧縮せず、その他の対応音声は PCM 24bit へ変換する。音声変換後の結合でも映像はパケットコピーし、二重にエンコードしない。解像度・各フレームの時刻・フレーム数・回転・色の原色と伝達特性を維持する。ProRes の出力レンジは limited に統一し、full 入力ではタグの変更だけでなく画素の full→limited 変換を行う。同一ピクセル形式で範囲だけを変換する場合も、実サンプルが変換されることを検証する。出力は入力と同じフォルダの `_mosaic.mov` で、衝突時の連番規則を MP4 と共有する。
- 通常 AAC 音声を含む iPhone MOV の補助 APAC 空間音声はコピーせず、AAC を保持する。APAC しかない動画は処理前に未対応として停止する。
- 元動画の位置情報、映像の元メタデータ、字幕、添付画像、別の映像トラックを出力へコピーしない。
- 途中ファイルは保存先の非公開一時ディレクトリ内に置く。成功した完成ファイルのみ、上書きを拒否する atomic hard link で公開する。失敗・キャンセル時に途中ファイルを削除する。
- 顔画像、埋め込み、解析結果はプロセス内だけに保持する。クラウド送信、解析テレメトリー、顔 DB、ブラウザサーバーは使わない。
- 同梱 ZIP 版は Python・GUI・顔認識モデル・動画ツールを含み、インストール・起動・解析・書き出しに Homebrew やネット接続を必要としない。アプリを版ごとの固定パスにコピーし、Finder アクションもその実行ファイルを呼ぶ。モデルとツールの欠落時は外部ダウンロードや PATH の別ツールへ切り替えず、再インストールを案内する。
- 解析後も自動書き出ししない。人物選択とプレビューの画面で「動画を保存する」を押すと書き出す。確認チェックによる制限は設けない。処理中の設定変更と二重書き出しは無効にする。

## 確認画面の操作

- IT に詳しくない利用者を想定し、初期状態では動画の選択と、自動で全員に雲を付ける流れを示す。加工画面では映像を常設し、横の人物選択・調整パネルを切り替える。設定を操作している間も映像を表示する。人物一覧は必要に応じて拡大できる。
- Mac の外観設定にかかわらず、アプリ・入力欄・ダイアログ・文字・選択色・スクロールバーは明示したライト配色を使う。映像の余白も明るくする。動画本来の色は変えない。
- 画面サイズに初期ウィンドウを合わせ、最小 640×480 まで設定をスクロールして到達できる。保存と処理中止はスクロール領域の外に固定する。長いファイル名や状態表示でウィンドウの最低幅を広げない。800×600 では人物カードのチェック欄まで初期表示に収める。
- 写真への移動・設定切り替え・範囲追加でもプレビューを常設する。範囲追加の終了はプレビューのボタンから操作できる。処理中は入力と設定の変更を無効にし、進捗と中止を示す。追加の確認チェックや保存先選択は求めない。

## 適用範囲

自動検出・顔識別の完全性、肖像権に関する法的な判断、公開先での再圧縮、対応外 HDR の互換性を保証するものではない。スコア閾値は実動画での誤分類率を測定した保証値ではない。選択した人が一部フレームで隠れることを許容し、曖昧な判定で別人を表示することを避ける。

## 確認済み

- Python 3.12.13 / arm64、PyAV 16.1.0、OpenCV 4.14.0.94、PySide6 6.12.0。
- 自動テスト 15 件成功: 顔の表示許可、曖昧な識別、中央が透ける PNG の拒否、HLG 基準白、6 種の YUV 形式での加工範囲外サンプル保持、透過部分保持、FFV1 出力の全サンプル一致、時刻、音声、フレーム数、MP4、キャンセル、入力変更・上書き拒否。
- OpenCV の公開サンプル顔を移動させた 20 フレームの動画で、全 20 フレームを検出し、顔候補 1 件と可逆出力を確認。
- 提供された 4K / 約 60fps / HLG / HEVC / AAC 動画の冒頭約 1 秒（69 フレーム）のコピーで解析と MP4 出力に成功。出力は 3840×2160、69 フレーム、HEVC、YUV 420 10bit、HLG。元動画は変更していない。
- Apple Silicon 専用 Homebrew Python.app の実画面が開き、未解析・未確認の書き出しが無効なことを確認。
- Automator workflow と app の plist は `plutil -lint` 成功。ユーザーの `~/Library/Services` へクイックアクションを新規登録。macOS の `pbs -dump` でも `public.movie` を受け取る Finder 専用サービスとして登録を確認。登録済み workflow を `automator -i` で起動し、短い実動画のパスが渡されて確認画面が開くことを実画面とプロセス引数で確認。
- `pip-audit --skip-editable`: 既知の脆弱性なし（この時点の監査データ）。

## 未確認・制限

- 実動画全体の全フレームについて、検出漏れ・誤分類・人物候補のまとまり・公開できる完成品質を保証していない。
- 動く顔の公開サンプルと短い実動画での成功は、全ての動画での顔検出精度や、肖像権の保護を証明しない。
- 4K 全解像度の全フレーム検出は時間がかかる。速度最適化のためにフレームを抜く実装は入れていない。
- プレビューは確認用に間引いて再生し、音声は再生しない。書き出しではフレームを間引かない。
- MKV の時刻精度はコンテナ由来。元の PTS の表現を完全に一致させる保証ではない。
- サンドボックス内の GUI 起動と VideoToolbox 初期化は拒否された。通常の Mac の画面サービスへ接続した実行では動作を確認。
- PyAV と OpenCV の macOS wheel に含まれる AVFoundation 用クラス名の重複がコンソールに警告される。カメラ取得は使用しない。ファイルのデコード、顔検出、GUI、HEVC 出力は確認済み。wheel の内部 dylib は変更していない。
